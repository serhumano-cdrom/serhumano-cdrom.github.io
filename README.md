# O que é ser humano? — CD-ROM de 2003

Edição HTML recuperada em 6 de outubro de 2026 para consulta em navegadores atuais.

O site preserva o índice original de artigos, as páginas dos autores e créditos, as imagens e os três vídeos. A redação dos textos mantém-se. Foram reparadas ligações e codificação, e os vídeos foram convertidos para MP4. As quatro figuras não encontradas nos dados incorporados estão assinaladas nas páginas correspondentes.

Publicação original: dezembro de 2003. ISBN 972-697-172-1. Depósito legal 198185/03.

A coordenação, equipas e editoras originais estão identificadas na página de créditos do CD. A conta deste repositório representa o projeto de disponibilização desta edição.

Todos os direitos reservados aos titulares originais. Não é concedida uma licença de reutilização aberta.

Para consulta local, abra `index.html` e mantenha a pasta `ficheiros` junto dele.
